# HTAutoParts

HTAutoParts is a static storefront for Honda and Toyota auto parts. Visitors can browse and search the catalog, view product details, manage a shopping cart, and use the checkout and contact pages.

## Current Features

- **Landing page:** Introduces the store and highlights featured parts.
- **Catalog:** Browse Honda and Toyota parts with search and filters.
- **Product pages:** View part details and add items to the cart.
- **Shopping cart:** Change quantities, remove items, and review totals; contents persist between visits.
- **Checkout:** Review an order summary and complete the demo checkout form.
- **Contact page:** Fill out a demo contact form and see an on-page confirmation.
